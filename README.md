# AI Sudoku Solving

## Overview
This project was developed as part of the Artificial Intelligence course. It presents a comparative study of different AI search and optimization algorithms for solving Sudoku puzzles and game search problems.

The project includes implementations of Constraint Satisfaction Problem (CSP) techniques, Simulated Annealing, MiniMax, and Alpha-Beta Pruning algorithms. :contentReference[oaicite:0]{index=0}

## Implemented Algorithms

- CSP Backtracking Search
  - Minimum Remaining Values (MRV)
  - Least Constraining Value (LCV)
  - Forward Checking

- Simulated Annealing (SA)

- MiniMax Algorithm

- Alpha-Beta Pruning

## Features

- Solves Sudoku puzzles using CSP Backtracking.
- Uses MRV, LCV, and Forward Checking heuristics.
- Implements Simulated Annealing for optimization-based solving.
- Demonstrates MiniMax and Alpha-Beta Pruning for game tree search.
- Measures algorithm performance and compares search strategies.
